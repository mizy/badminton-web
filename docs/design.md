# Badminton Web — 仿真级网页羽毛球

## 核心理念

画面用最简单的 3D 几何体，全部精力砸在**控制手感 + 技战术还原**上。

## 视角

第三人称后上方，体现球的高度感和前后场空间。

## 渲染策略

极简几何体，不做精细角色模型：
- 球员 = 圆柱体(躯干) + 球体(头) + 胶囊体(手臂+拍)
- 羽毛球 = 半球体(球头) + 锥体(裙摆) — 共 ~20 三角面
- 球拍 = 细圆柱(拍杆) + 圆环(拍框) + 网格线(4条线段)
- 球场 = 纹理平面 + 白线 + 网(半透明面)

风格走极简风，干净、色彩鲜明、帧率高。

## 物理核心

### 球气动积分（RK4）

```ts
// 每帧 8-16 sub-step
drag = -0.5 * ρ * Cd * A * |v| * v / m    // Cd 随速度变化
magnus = Cm * (ω × v) / m                  // 旋转偏转
gravity = g
```

### 拍面碰撞

球头与拍面 OBB 相交 → 计算相对速度 → 分解法向/切向 → 拍线形变模型 → 输出新球速 + 反馈

## 核心手感模型

真实羽毛球手感 = **步法到位度 × 击球时机 × 拍面角度 × 力量**

### 步法系统
- 球员有加速度和减速度，不是瞬移
- 急转方向有 inertia（动量惯性）
- 步频越快实际移动越慢（模拟真实步法调整）
- 站位越到位击球选择越多

### 击球合成
```
Power Charging (按住蓄力) → Release
  → Timing Check (来球高度 vs 球员位置)
  → Racket Angle (方向输入)
  → Shot Outcome (球速 + 轨迹 + 旋转)
```

### 真实技战术映射

| 操作组合 | 打出 | 实战用途 |
|---------|------|---------|
| 跑到球下 + 高点 + 扣杀 | 杀球 300+ km/h | 进攻得分 |
| 跑到球下 + 高点 + 轻力 | 吊球 | 打乱节奏 |
| 后撤 + 低点 + 大力 | 高远球 | 防守过渡 |
| 身前 + 平拍面 + 快击 | 平抽 | 双打平抽挡 |
| 网前 + 切拍面 + 轻力 | 网前小球 | 迫使挑球 |
| 网前 + 向上拍面 + 发力 | 挑球/推球 | 摆脱网前 |

## AI 对手

三层架构：战术层(选择打法) → 决策层(选择落点) → 执行层(移动到位)

难度 = 反应时间 + 到位度 + 失误率。

## 开发路线

| Phase | 内容 | 时间 |
|-------|------|------|
| P1 | 球物理（自由落体→发球→飞行），Three.js 场景，视角控制 | 1周 |
| P2 | 碰撞系统（拍面+网+场地），击球反馈 | 1周 |
| P3 | 角色控制器 + 输入映射 + 球员移动（惯性步法） | 1周 |
| P4 | 击球合成系统 + 6 种球路 + 合法性检查 | 1周 |
| P5 | AI 对手（决策+移动+回球） | 2周 |
| P6 | 比赛规则系统（BWF 计分） | 3-4天 |
| P7 | 联机模式（WebSocket 可选） | +2周 |
