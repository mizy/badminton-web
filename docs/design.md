# Badminton Web — 仿真级网页羽毛球

## 核心理念

画面用最简单的 3D 几何体，全部精力砸在**控制手感 + 技战术还原**上。

**方向定位**：单机模拟类，不做联机。目标是让玩家在浏览器里就能体验到接近真实羽毛球的技战术深度和装备差异感。

---

## 视角

第三人称后上方，体现球的高度感和前后场空间。

---

## 渲染策略

极简几何体，不做精细角色模型：
- 球员 = 圆柱体(躯干) + 球体(头) + 胶囊体(手臂+拍)
- 羽毛球 = 半球体(球头) + 锥体(裙摆) — 共 ~20 三角面
- 球拍 = 细圆柱(拍杆) + 圆环(拍框) + 网格线(4条线段)
- 球场 = 纹理平面 + 白线 + 网(半透明面)

风格走极简风，干净、色彩鲜明、帧率高。

## 物理核心

### 球气动积分（RK4）

```ts
// 每帧 8-16 sub-step
drag = -0.5 * ρ * Cd * A * |v| * v / m    // Cd 随速度变化
magnus = Cm * (ω × v) / m                  // 旋转偏转
gravity = g
```

### 拍面碰撞

球头与拍面 OBB 相交 → 计算相对速度 → 分解法向/切向 → 拍线形变模型 → 输出新球速 + 反馈

## 核心手感模型

真实羽毛球手感 = **步法到位度 × 击球时机 × 握拍类型 × 拍面角度 × 力量**

### 步法系统（真实步法分类）

模拟真实羽毛球步法，不是简单的"WASD 移动"：

| 步法类型 | 触发条件 | 速度 | 体耗 | 用途 |
|---------|---------|:---:|:----:|------|
| **启动步（Split Step）** | 对手击球瞬间自动触发 | — | 低 | 预判启动，影响下一拍速度 |
| **并步（Chasse）** | 横向近距离移动 | ★★★ | 低 | 中场左右移动 |
| **交叉步（Cross Step）** | 横向远距离移动 | ★★★★ | 中 | 大范围横向移动 |
| **垫步（Hop Step）** | 前后短距离调整 | ★★★ | 低 | 微调站位 |
| **蹬跨步（Lunge）** | 向四个方向快速发力 | ★★★★★ | 高 | 接杀、上网扑球 |
| **后退步（Backward）** | 向后场移动 | ★★ | 高 | 正手/反手/头顶后退 |
| **上网步（Forward）** | 向前场移动 | ★★★ | 中 | 网前球 |

- 不同步法之间的切换有过渡帧（不能从后退直接变蹬跨）
- 步法选择由输入方向 + 当前站位 + 来球位置自动决定，玩家控制的是"意图方向"
- 到位度影响击球质量：100% 到位 → 任意球路，50% 到位 → 只有防守球路

### 握拍系统

正反手握拍切换由球的位置自动决定，但高阶玩家可通过输入干预：

| 握拍类型 | 适用场景 | 影响 |
|---------|---------|------|
| **正手握拍** | 正手位高球/杀球/高远 | 正手球速 +10%，反手球速 -30% |
| **反手握拍** | 反手位/网前反手 | 反手控制 +15%，杀球力度 -20% |
| **网前握拍（钳式）** | 网前搓球/放网 | 网前精度 +25%，大力击球 -40% |
| **杀球握拍（拳式）** | 重杀/点杀 | 杀球力度 +15%，控制 -15% |

- 握拍切换有冷却（模拟换握时间）
- 握拍不对强行出球 → 质量大幅下降/失误

### 击球合成

```
Power Charging (按住蓄力) → Release
  → Timing Check (来球高度 vs 球员位置)
  → Grip Check (当前握拍是否匹配)
  → Racket Angle (方向输入)
  → Shot Outcome (球速 + 轨迹 + 旋转 + 质量)
```

### 真实技战术映射

当前 6 种球路 + 细化：

| 球路 | 操作条件 | 球速范围 | 实战用途 |
|------|---------|:-------:|---------|
| **重杀（Smash）** | 高点 + 正手握拍 + 全力 | 280-380 km/h | 直接得分 |
| **点杀（Flick Smash）** | 高点 + 快速挥拍 | 260-320 km/h | 打空档 |
| **劈杀（Slice Smash）** | 高点 + 切拍面 | 240-300 km/h | 大斜线 |
| **快吊（Fast Drop）** | 高点 + 中等力度 | 180-240 km/h | 快节奏 |
| **慢吊（Slow Drop）** | 高点 + 轻力 | 100-160 km/h | 贴网 |
| **高远球（Clear）** | 低点 + 大力 | 200-280 km/h | 防守过渡 |
| **平高球（Drive Clear）** | 身前 + 平拍面 | 240-300 km/h | 压后场 |
| **平抽（Drive）** | 身前 + 发力 | 260-340 km/h | 双打平抽 |
| **搓球（Net Spin）** | 网前 + 切拍面 | 20-60 km/h | 旋转贴网 |
| **放网（Net Drop）** | 网前 + 轻放 | 10-40 km/h | 贴网 |
| **勾对角（Cross Net）** | 网前 + 斜切 | 30-70 km/h | 调动对手 |
| **挑球（Lift）** | 网前低点 + 上挑 | 120-200 km/h | 摆脱网前 |
| **推球（Push）** | 网前 + 快速前推 | 180-260 km/h | 压反手 |
| **扑球（Net Kill）** | 高点网前 + 下压 | 200-300 km/h | 封网得分 |

## 装备系统（全新）

装备影响真实物理参数，不搞数值堆叠。球员出场前配置 Loadout。

### 球拍（Racket）

| 参数 | 取值范围 | 影响 |
|------|---------|------|
| **重量（Weight Class）** | 2U(90-94g) / 3U(85-89g) / 4U(80-84g) / 5U(75-79g) | 轻→挥速快但借力差，重→势能大但挥速慢 |
| **平衡点（Balance）** | HH(头重) / Even(均衡) / HL(头轻) | 头重→杀球沉，头轻→平抽快 |
| **中杆硬度（Shaft Stiffness）** | Flexible / Medium / Stiff / Extra Stiff | 软→好借力但指向差，硬→指向精准但发力门槛高 |
| **拍框形状（Frame）** | ISO(方头) / Oval(圆头) | ISO→甜区大，Oval→精准 |
| **拉线磅数（Tension）** | 20-32 lbs | 低→弹性好+甜区大，高→控制精+发力门槛高 |
| **拍线线径（String Gauge）** | 0.65-0.75 mm | 细→弹性好+不耐用，粗→耐打+弹性差 |

**球拍手感公式**：

```
挥重 = f(重量, 平衡点)           → 影响挥速
出球速度 = f(挥速, 中杆形变, 线床弹性)
控制精度 = f(中杆硬度, 磅数, 拍框)
力量传导 = f(中杆硬度, 重量)
```

### 手胶（Grip）

| 参数 | 影响 |
|------|------|
| 厚度（G2/G3/G4/G5） | 粗→握拍更稳但灵活性降低 |
| 材质（PU / 毛巾 / 龙骨） | PU→减震好，毛巾→吸汗，龙骨→防滑 |

### 羽毛球（Shuttlecock）

| 参数 | 取值范围 | 影响 |
|------|---------|------|
| 类型 | 鹅毛 / 鸭毛 / 尼龙 | 鹅毛→飞行最稳，尼龙→耐用但手感硬 |
| 速度（Speed） | 76 / 77 / 78 / 79 | 高→飞行更远（温度海拔补偿） |
| 耐打度 | 1-10 | 影响比赛中的球速衰减 |

### 球鞋（Shoes）

| 参数 | 影响 |
|------|------|
| 鞋底抓地力 | 影响急停/启动速度 |
| 缓震 | 影响体力消耗速率 |

### Loadout 配置

```
PlayerLoadout {
  racket: RacketSpec
  grip: GripTape
  shuttlecock: ShuttlecockSpec
  shoes: ShoesSpec
}
```

- **选择装备在主菜单进行**，比赛过程中不可更换
- AI 对手的 Loadout 影响其打法风格（头重拍 → AI 倾向杀球，头轻拍 → AI 倾向拉吊）
- 装备参数在 `game/reducer.ts` 中注入到物理计算和击球合成中

## 进阶技战术系统（Phase 8）

### 站位系统

| 站位 | 触发 | 加成 |
|------|------|------|
| **进攻站位** | 在前半场 + 球在对手半场 | 杀球+网前反应加快 |
| **防守站位** | 在后半场 + 球在自己半场 | 接杀/挑球加成 |
| **均衡站位** | 中场 | 无加成无减益 |
| **失位惩罚** | 站错位置 | 击球质量下降 + 体力额外消耗 |

### 体能系统细化

当前 `stamina.ts` 的简单体耗升级为：

```
体力 = f(基础体能, 步法效率, 鞋底缓震, 当前负荷)
疲劳 = f(激烈程度, 回合长度, 环境温度)
```

- 长时间多拍 → 步法变慢 + 杀球力度下降 + 判断延迟增加
- 体力低于 30% → 重大失误率上升（模仿真实比赛中的体能下降）

### AI 打法风格

AI 不再只有难度预设，而是增加"打法人格"：

| 风格 | 特点 | 装备倾向 |
|------|------|---------|
| **进攻型（Attack）** | 抢高点、频繁杀球 | 头重 + 硬中杆 |
| **拉吊型（Rally）** | 四方球调动、耐力战 | 均衡 + 软中杆 |
| **防守反击（Counter）** | 接杀打空档、网前小球 | 头轻 + 高磅 |
| **双打型（Double）** | 封网快、平抽挡 | 头轻 + 中杆适中 |

## AI 对手

三层架构：战术层(选择打法风格+球路) → 决策层(选择落点) → 执行层(移动到位)

难度调节：
- **Easy**：反应慢、到位差、回球质量低
- **Medium**：反应正常、移动到位率 70%、偶尔失误
- **Hard**：反应快、移动到位率 90%、失误极少
- **Pro**：接近真实职业选手，打法有风格特征
